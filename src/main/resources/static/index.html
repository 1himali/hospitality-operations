What is Mock Mode?

Mock mode replaces third-party service integrations with simulated responses, allowing testing and development without external dependencies.

When enabled:

  • Third-party order listings return sample data
  • Orders are processed locally with mock confirmations
  • No external network calls are made

Note: Mock mode controls are restricted to Admin and Owner roles.
